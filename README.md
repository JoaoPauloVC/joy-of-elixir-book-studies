# Projeto Joy of Elixir

Projeto iniciado para resolver os exercícios do livro Joy of Elixir, do Ryan Bigg.

## Organização

A organização do projeto se dá em pastas com as 4 partes do livro. Dentro de cada pasta, estão os capítulos em arquivos Elixir próprios. Quando cabível, os exercícios estão como comentários da função logo abaixo, que resolve o problema em questão.
